# DIKWP-QINGYUAN-OS 1.0.0

## Proactive Cognitive-Environment Immunity, Manipulation Circuit-Breaking, and Evidence Return

DIKWP-QINGYUAN-OS is an offline-capable, auditable research runtime for reducing high-stakes misinformation, manipulative persuasion, addictive amplification, vulnerable-audience exploitation, and monetized pseudo-knowledge.

It does **not** treat negative emotion as falsity. Evidenced warnings, criticism, dissent, whistleblowing, grief, and bad news are protected. Positive, inspirational, healing, and success narratives receive the same evidence and incentive audit.

### Three non-isomorphic world models

1. provenance and verifiability;
2. pressure, addiction, and commercial incentives;
3. harm, autonomy, and expression rights.

The models remain separate. No single moral or truth score is used.

### Intervention ladder

The runtime can recommend provenance return, contextualization, user-controlled friction, de-amplification of compulsive recommendation loops, monetization review, temporary reviewable quarantine, authorized domain review, or urgent human safeguarding. Every high-impact action is named, time-limited, reversible where possible, and appealable. The `shield` command can actively transform a user-controlled local feed copy by disabling autoplay and recommendation boosts, attaching context, or holding high-risk items from the default view while preserving originals in an appealable hash archive.

```text
automatic_external_action_authority = 0
automatic_deletion = false
```

### Quick start

```bash
python DIKWP_QINGYUAN_OS.pyz inspect
python DIKWP_QINGYUAN_OS.pyz demo --output outputs/demo
python DIKWP_QINGYUAN_OS.pyz suite --output outputs/reference
python DIKWP_QINGYUAN_OS.pyz assess my_item.json --output outputs/my_item
python DIKWP_QINGYUAN_OS.pyz shield demo_feed/mixed_feed.json --output outputs/shielded_feed
python DIKWP_QINGYUAN_OS.pyz verify outputs/my_item/evidence_ledger.jsonl
```

Start custom assessments from `templates/content_item_template.json`. See `README_CN.md` and `docs/` for the full architecture, governance, real-life support protocol, threat model, schemas, and standardization profile.

### Rights firewall

- no secret permanent person blacklist;
- no suppression merely for criticism, pessimism, minority views, or public-interest reporting;
- no diagnosis of mental illness or capacity from beliefs;
- no covert persuasion or forced belief change;
- claim-level reasons, evidence return, independent appeal, and expiry for temporary actions;
- unobserved outcomes remain a reality debt and must recalibrate the models.
