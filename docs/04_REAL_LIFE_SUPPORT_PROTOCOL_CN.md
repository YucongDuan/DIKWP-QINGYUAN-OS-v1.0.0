# 现实生活中的非强制认知保护协议

现实中的错误信念、受骗、上瘾、高控制社群和利益诱导不能只靠“指出事实”解决。直接羞辱、围攻、强制断联或秘密操纵常会强化防御和依赖。

## 三种路径

### 当事人主动求助

共同画出“主张—来源—利益—行动—后果”图，只验证一个最关键且可区分的主张；恢复替代信息源和选择。

### 当事人暂不愿讨论

不强迫世界观改变。保护共享财产、未成年人、组织职责和不可逆决策边界；留下简短书面证据包和重新讨论的开放入口。

### 存在迫近危险

依据适用法律和职责，由有资格的人使用医疗、金融、学校、法律、平台或紧急安全流程。系统不自行诊断、不秘密监控、不代替授权主体。

## 禁止策略

- 给人贴“认知低”“有问题”“不可救药”的标签；
- 冒充朋友、专家或平台；
- 隐瞒干预目的；
- 通过恐惧、羞辱、断联、经济控制或重复轰炸强制改信；
- 因政治、宗教、文化或少数观点而采取限制；
- 在没有合法权限时扣押设备、资金或身份文件。
