# Data and Privacy

The prototype processes local JSON files and makes no network requests. Production systems should apply data minimization, purpose limitation, retention limits, access controls, encryption, and regional legal requirements.

Do not collect private conversations, health data, family disputes, browsing histories, biometric data, or financial records merely to improve a risk score. Offline support cases should be documented only with consent or a clear lawful safeguarding duty. Remove unnecessary identifiers from shared evaluation datasets.

The appeal process must provide access to the item-level record without exposing unrelated private data or protected sources.
