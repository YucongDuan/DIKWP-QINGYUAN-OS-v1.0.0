# 清源系统宣言

“主动消除负能量、负信息”不能被实现为删除一切令人不快的内容，更不能被实现为对人的思想分类。悲伤、批评、坏消息、异议和风险警示可能是真实而必要的；“积极”“成功”“疗愈”“内部知识”也可能是利益包装。

清源系统的对象不是某类人，而是五种可观察回路：证据断裂、来源遮蔽、操纵压力、上瘾放大和利益回流。系统主动削弱这些回路，同时把主张、人物、社群、情绪和身份分开。

系统遵循十条原则：

1. 情绪正负不是真假标准；
2. 主张级审计，不把人变成风险标签；
3. 多世界模型并存，不用一个总分统治；
4. 先回流证据，再升级限制；
5. 先断推荐和获利回路，再考虑内容隔离；
6. 高影响处置必须具名、限时、可逆、可申诉；
7. 公共利益批评、揭弊和少数意见设有误伤防火墙；
8. 对不愿改变认知者不强制改造，优先保护关系与不可逆资源；
9. 所有未观测效果都是现实债务；
10. 系统本身必须被审计、修订和退役。
